# RussLand

Веб-приложение (PWA) для изучения русского языка франкоязычными. Работает на iPhone и Android: открыть сайт → «На экран Домой». После первой загрузки работает без интернета.

**Сайт:** https://pla3ma2.github.io/RussLand/

## Что внутри

- **Leçons** — 6 уроков-сцен с персонажами (знакомство, кафе, «я не понимаю», город, магазин, в гостях). Каждый урок: *Écoute* (диалог, тап по слову → звук + транслитерация и перевод над словом) → *Construis* (пазл, окончания меняются цветом падежа + задания) → *Comprends* (объяснение от персонажа) → *Parle* (сказать самому, сравнить с моделью) → *Joue la scène* (ролевая игра) → итог «Maintenant tu sais…».
- **Lecture** — режим чтения по принципам русских букварей: 9 ступеней, буквы звучат как звуки, слоги, пары твёрдый/мягкий, слова с переводом, упражнения на слух.
- **АБВ** — алфавит доступен с любого экрана: звук каждой буквы, подсказка, пример.
- **Révision** — интервальное повторение (FSRS): фразы из пройденных уроков возвращаются вовремя.
- **Carte** — «скелет» языка: таблица падежей и глаголов, клетки открываются по ходу уроков.
- Офлайн-распознавание речи (Vosk) — по желанию, включается кнопкой.

## Как устроено

```
content/
  characters.json   персонажи и голоса
  levels/*.json     уроки (диалоги, пазлы, задания, объяснения, словарик)
  reading.json      ступени чтения
  alphabet.json     алфавит: группы, звуки, подсказки
  carte.json        что показывается на «Карте»
tools/build_content.py   ударения (silero-stress), формы слов (pymorphy3), озвучка (Silero TTS), проверки
src/                     приложение (Vite + TypeScript, без фреймворков)
.github/workflows/       сборка на GitHub: контент → озвучка → модель Vosk → сайт
```

Озвучка и модель распознавания создаются автоматически в GitHub Actions при каждом изменении.

### Как добавить или поправить урок

1. Отредактировать файл в `content/levels/` (или создать новый по образцу).
2. Ручное ударение — знак `+` перед гласной: `Л+ука`, `по-р+усски`.
3. Закоммитить — через несколько минут сайт обновится сам. Конвейер сам проверит, что в режиме «Чтение» слова состоят только из уже изученных букв, и предупредит о словах без перевода.

## Локальный запуск

```bash
npm install
pip install -r tools/requirements.txt
python tools/build_content.py   # без озвучки: приложение говорит голосом браузера
npm run dev
```
